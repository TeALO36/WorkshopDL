Version 2.0.8
- [+] The Launcher is now the ONE and only WorkshopDL application, with a
      brand-new interface. The old WorkshopDL.exe window is gone, and so is
      the "open in WorkshopDL" hand-over button — everything happens in-app.
- [+] "Mettre à jour" button restores the classic update function: it updates
      SteamCMD and refreshes the supported-games list.
- [+] Unchecking "Mode anonyme" now opens a Steam login pop-up (account name)
      and launches steamcmd so you can sign in — account mode succeeds where
      anonymous downloads are refused.
- [+] New "Aide / Support" and "Ouvrir le dernier dossier" buttons.
- [*] Honest download status: success is reported ONLY when the item folder
      really contains files — no more false "installation terminée".

Version 2.0.7
- [*] Installer: cleanly uninstalls any previous WorkshopDL version before
      installing — no stale registry entry, files or shortcuts are left
      behind; your settings (WorkshopDL.ini) are preserved
- [*] Installer: fixed the "Internal error: CallSpawnServer: Unexpected
      response: $0" error that could abort the installation when choosing
      the "all users" install mode (the "launch now" box is now skipped in
      that mode; the shortcuts are created as usual)

Version 2.0.6
- [+] New one-click Windows installer (per-user, no admin required)
- [+] Launcher: force the target game with a selector — override the
      auto-detected game with any detected or supported game (e.g. Spacewar)
- [+] Launcher: cancel a running download at any time
- [+] Launcher: hide/ignore games from the detected list
      (right-click a game -> hide; "show all hidden" restores them)
- [+] Launcher: analysis now retries automatically when Steam rate-limits
      requests (HTTP 429) and shows a clear message instead of a raw error
- [*] Launcher: much more reliable game detection (workshop links no longer
      attributed to the wrong game, e.g. Golf maps detected as Garry's Mod)
- [*] Launcher: clearer interface — result panel with item details,
      full install paths, resizable game list

Version 2.0.5
- [+] Added Golf With Your Friends (AppID 431240) to the supported games list
- [+] Golf With Your Friends workshop maps can now be downloaded and installed
      (tested with Pyramid Par: https://steamcommunity.com/sharedfiles/filedetails/?id=3764231585)
- [*] Supported games list refreshed (list version 21)
- [*] Removed the dead "project outdated" notice (the repository it pointed to no longer exists)
