WorkshopDL 2.0.8 — Quick start / Démarrage rapide
=================================================

ENGLISH
-------
1. Double-click "WorkshopDL Launcher".
2. Paste a Steam Workshop URL and click "Analyser le lien".
   The game is detected automatically — no supported-list update needed.
3. Click "Télécharger". If the download is refused anonymously, uncheck
   "Mode anonyme": a pop-up asks you to sign in to your Steam account
   (steamcmd opens so you can type your password + Steam Guard), then
   click "Télécharger" again.
4. Wrong game detected? Use the target selector above the buttons to force
   any other detected or supported game (e.g. Spacewar).
5. "Mettre à jour" updates SteamCMD and the supported-games list.
   "Aide / Support" opens the issue tracker; "Ouvrir le dernier dossier"
   reopens the folder of your last download.
6. Right-click a game in the list to hide it; "Réafficher tous les jeux
   masqués" brings them back. Games added with "+ Dossier manuel" are kept.

FRANÇAIS
--------
1. Double-cliquez sur « WorkshopDL Launcher ».
2. Collez un lien du Steam Workshop puis cliquez sur « Analyser le lien ».
   Le jeu est détecté automatiquement — aucune mise à jour de liste nécessaire.
3. Cliquez sur « Télécharger ». Si le téléchargement anonyme est refusé,
   décochez « Mode anonyme » : un pop-up propose de vous connecter à votre
   compte Steam (steamcmd s'ouvre pour saisir mot de passe + Steam Guard),
   puis cliquez de nouveau sur « Télécharger ».
4. Mauvais jeu détecté ? Utilisez le sélecteur de jeu cible au-dessus des
   boutons pour forcer un autre jeu détecté ou compatible (ex. Spacewar).
5. « Mettre à jour » met à jour SteamCMD et la liste des jeux compatibles.
   « Aide / Support » ouvre le suivi des problèmes ; « Ouvrir le dernier
   dossier » rouvre le dossier de votre dernier téléchargement.
6. Faites clic droit sur un jeu pour le masquer ; « Réafficher tous les jeux
   masqués » les restaure. Les dossiers ajoutés sont mémorisés.
