WorkshopDL 2.0.7 — Quick start / Démarrage rapide
==================================================

ENGLISH
-------
1. Double-click "WorkshopDL Launcher" (recommended) or "WorkshopDL".
2. Paste a Steam Workshop URL and click "Analyze".
   The launcher detects the game automatically — no supported-list update needed.
3. Click "Download". If the download is refused anonymously, uncheck
   "Anonymous mode" and sign in with the Steam account that owns the game.
   A "Cancel" button lets you stop a running download at any time.
4. Wrong game detected? Use the target selector above the buttons to force
   any other detected or supported game (e.g. Spacewar).
5. Right-click a game in the list to hide it; use "show all hidden games"
   to bring them back. Games you add manually with "+ Manual folder"
   are remembered.

The classic WorkshopDL window still works exactly as before
(supported list now includes Golf With Your Friends, AppID 431240).

FRANÇAIS
--------
1. Double-cliquez sur « WorkshopDL Launcher » (recommandé) ou « WorkshopDL ».
2. Collez un lien du Steam Workshop puis cliquez sur « Analyser ».
   Le jeu est détecté automatiquement — aucune mise à jour de liste nécessaire.
3. Cliquez sur « Télécharger ». Si le téléchargement anonyme est refusé,
   décochez « Mode anonyme » et connectez-vous avec le compte Steam
   qui possède le jeu. Un bouton « Annuler » stoppe un téléchargement
   en cours à tout moment.
4. Mauvais jeu détecté ? Utilisez le sélecteur de jeu cible au-dessus des
   boutons pour forcer un autre jeu détecté ou compatible (ex. Spacewar).
5. Faites clic droit sur un jeu de la liste pour le masquer ; « Réafficher
   tous les jeux masqués » les restaure. Les jeux ajoutés avec
   « + Dossier manuel » sont mémorisés.

La fenêtre WorkshopDL classique fonctionne comme avant
(liste compatibles incluant Golf With Your Friends, AppID 431240).
